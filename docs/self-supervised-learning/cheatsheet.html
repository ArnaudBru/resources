Cheat sheet — Self-Supervised Learning

Le self-supervised learning regroupe les méthodes dont le signal d'entraînement provient de la donnée elle-même, sans annotation humaine. Contrastif, clustering, distillation et masking en sont des sous-familles.

La taxonomie

Premier axe de classification : joint-embedding (comparer les représentations de deux vues) ou reconstructif (exploiter la structure interne d'une seule image).

Self-Supervised Learning
│
├─ JOINT-EMBEDDING  — comparer les représentations de deux vues
│   ├─ Contrastif .............. SimCLR, MoCo v1/v2/v3
│   ├─ Clustering ............... SwAV, DeepCluster
│   ├─ Self-distillation ........ BYOL, SimSiam, DINO, DINOv2, DINOv3
│   └─ Covariance ............... Barlow Twins, VICReg
│
└─ RECONSTRUCTIF / PRÉDICTIF  — exploiter une seule image
    ├─ Masked modeling .......... BEiT, MAE, iBOT, VideoMAE
    ├─ Prédiction latente ....... data2vec, I-JEPA, V-JEPA, V-JEPA 2
    └─ Pretext tasks ............ RotNet, Jigsaw, Colorization, Context pred.
Méthodes hybrides. Les modèles les plus performants combinent plusieurs familles : iBOT = masked modeling + self-distillation ; DINOv2/v3 = DINO (global) + iBOT (dense) ; JEPA = masking + cible latente produite par un teacher EMA.

Les 7 familles

Chaque famille est caractérisée par son mécanisme d'apprentissage et sa parade au collapse.

Contrastif 2018 – 2021

Rapprocher les vues d'une même image, éloigner toutes les autres.
Anti-collapse : les négatifs repoussent. Clé : température, taille de batch, choix des augmentations.
SimCLR · MoCo v1/v2/v3 · CPC · (CLIP = contrastif mais weakly supervised)

Clustering 2018 – 2020

Assigner les vues à des prototypes partagés, sous contrainte d'équipartition.
Anti-collapse : l'équipartition (Sinkhorn) force l'étalement sur tous les prototypes.
SwAV (+ multi-crop, hérité par DINO) · DeepCluster

Self-distillation 2020 – aujourd'hui

Un côté prédit l'autre ; la cible ne reçoit pas de gradient.
Anti-collapse : une asymétrie entre les deux branches, sous deux formes distinctes — architecturale chez BYOL/SimSiam (predictor + stop-gradient), statistique chez DINO (centering + sharpening des sorties du teacher, sans predictor). Le stop-gradient est commun aux deux.
BYOL · SimSiam · DINO · DINOv2 · DINOv3 ← SOTA

Covariance 2021

Décorréler les dimensions pour qu'aucune ne soit redondante.
Anti-collapse : contrainte explicite sur la matrice de covariance (ni négatifs, ni EMA, ni predictor).
Barlow Twins · VICReg

Masked image modeling 2021 – aujourd'hui

Masquer une grande part de l'image et reconstruire ce qui manque.
Pas de problème de collapse : la cible est externe, la sortie constante est simplement fausse.
MAE (pixels, 75 %) · BEiT (tokens discrets) · iBOT (cible = teacher EMA) · VideoMAE (90 %+)

Prédiction latente 2022 – aujourd'hui

Prédire la représentation des parties masquées, pas leur contenu.
Collapse possible (la cible vient du modèle) → target encoder EMA + predictor, comme BYOL.
data2vec · I-JEPA · V-JEPA · V-JEPA 2 (world model, robotique)

Pretext tasks 2015 – 2018

Résoudre une tâche artificielle dont la réponse est connue d'avance.
Pas de collapse — mais plafonnent : le modèle n'apprend que le minimum nécessaire à la tâche.
Context prediction · Jigsaw · Colorization · RotNet

Mécanismes anti-collapse

Le collapse — l'encodeur produit le même vecteur pour toute image — ne concerne que les méthodes joint-embedding, dont la cible est générée par le modèle lui-même.

MécanismeSuffisant seul ?Preuve / contre-preuve
NégatifsouiSimCLR : ni predictor, ni EMA, ni stop-gradient
Clustering + équipartitionouiSwAV (mais codes détachés du graphe)
Contraintes de covarianceouiBarlow Twins, VICReg : aucun autre mécanisme
Stop-gradient + predictorouiSimSiam — sans EMA, sans négatifs
Stop-gradient + centering/sharpeningouiDINO — voie alternative, sans predictor
Stop-gradient seulnonSimSiam sans predictor → collapse
EMA seulnonBYOL sans predictor → collapse malgré l'EMA
Rôle du teacher EMA. L'EMA est souvent présenté comme le mécanisme anti-collapse de BYOL. Les ablations de SimSiam montrent qu'il n'est pas nécessaire : c'est le couple predictor + stop-gradient qui empêche le collapse, l'EMA apportant performance et stabilité.
Synthèse. Trois mécanismes suffisent isolément — négatifs, contrainte de distribution (équipartition, covariance, ou centering/sharpening), asymétrie architecturale. L'EMA n'en fait pas partie : il ne suffit seul dans aucun cas, mais améliore la plupart des méthodes.

Asymétrie MAE / DINO. MAE domine en fine-tuning et reste moyen en linear probe ; DINO présente le profil inverse. La reconstruction pixel produit des features locales et texturales — bonne initialisation, faible séparabilité linéaire — là où la distillation produit des features globales séparables. iBOT et DINOv2 combinent les deux losses.

Précisions de vocabulaire

  • SSL et contrastif ne s'opposent pas : le contrastif est une sous-famille du SSL, au même titre que le clustering ou la distillation.
  • « Non-contrastif » désigne les méthodes SSL sans exemples négatifs (BYOL, DINO, SimSiam). L'opposition est interne au SSL.
  • « Collapse » recouvre deux phénomènes distincts : en SSL, un encodeur produisant le même vecteur pour toute image ; en attention (entropy collapse), un softmax qui sature sur un seul token.
  • « Masking » désigne soit une restriction de l'attention entre tokens (masque causal), soit le retrait de contenu d'entrée qui définit la tâche d'apprentissage (MAE, JEPA).
  • CLIP est contrastif mais relève de la supervision faible (natural language supervision) : les légendes sont d'origine humaine.
